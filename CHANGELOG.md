# Changelog

All notable changes to the "BearTheme" extension will be documented in this file.

## [1.2.0] - 2026-09-11

### Added
- Added 6 new Catppuccin-inspired pastel themes:
  - `Bear Pastel Latte (Light)`
  - `Bear Pastel Matcha (Light)`
  - `Bear Pastel Blossom (Light)`
  - `Bear Pastel Mocha (Dark)`
  - `Bear Pastel Frappé (Dark)`
  - `Bear Pastel Macchiato (Dark)`
- Full workbench UI tokens (over 85 color rules) for all themes.
- Updated documentation and added MIT License.

## [0.1.0] - 2026-09-11

### Added
- Added 5 new theme variations:
  - `Bear Polar (Light)`
  - `Bear Honey (Light)`
  - `Bear Cyber (Dark)`
  - `Bear Forest (Dark)`
  - `Bear Midnight (Dark)`
- Expanded TextMate token rules and workbench coverage.

## [0.0.4]

- Color palette adjustments.

## [0.0.1]

- Initial release of BearTheme and BearTheme High Contrast.
